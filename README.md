# Jammming

  Jammming es una Aplicación web, que desarrollé para CodeCademy.

  La idea es que busques tus canciones FAV en Spotify, crees una lista y la guardes directamente en tu Spofity.

## Caracteristicas de la App:

Buscar canciones por nombre, artista o álbum.
Añade canciones a una lista.
Elimina canciones de una lista tuya.


## Tecnologías utilizadas 

- React
- JavaScript
- CSS
- Vite
- Api de Spotify
